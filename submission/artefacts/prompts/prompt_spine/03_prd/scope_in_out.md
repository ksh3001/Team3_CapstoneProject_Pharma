# Prompt 03 — Scope In / Out

| In scope (capability) | Out of scope |
|---|---|
| Evidence cite / reconcile / flag / abstain for batch readiness **support** | Batch disposition / certification by software |
| PV intake extract / normalize / duplicate **candidates** / clock provenance | Final PV safety or reportability decisions |
| Supply **draft options** only | Reserve, allocate, ship, status change, recall |
| Fail-closed contracts and negative tests | Side-effecting tools in assessed mode |
| Offline deterministic + AI-disabled runbooks | Hard dependency on live model region |
| Measure proxies and honest TCO | Claiming board −14% achieved without baseline |
| Authority-filtered knowledge as data | Untrusted docs as instructions |

Any later prompt that pulls an “Out of scope” item in without change control violates this PRD.
