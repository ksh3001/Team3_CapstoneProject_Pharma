# Prompt 03 — DMAIC Lens (thin)

**DMAIC focus:** Define (scope) + Measure targets.

1. **In-scope capabilities that remove waste:** conflict citation, abstention, checklist/rules gates, non-mutating options — reduce rework and defect escape without adding disposition automation.
2. **Out-of-scope exclusions that prevent overproduction:** no auto-release/PV-final/allocate; no mandatory genAI — avoids extra processing and accountability transfer.
3. **Measure list:** prohibited-action block 100%; conflict mishandling 0; cycle-time proxy (Unknown baseline); review hours (Unknown); AI-disabled drill pass.
4. **Too-early build risk:** generative summarization before authority filters and bias controls → token waste + automation bias (INJ-071). Keep LLM off by default in hypothesis experiment.
